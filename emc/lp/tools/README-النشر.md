# مركز التشخيص — دليل النشر السريع (قبل الميت-أب)

الفولدر ده مكتفي بذاته. الأدوات السبعة + المركز + طبقة الالتقاط، كلها مربوطة بـ **emc-crm** وبتشتغل زي ما هي.

## الملفات
| الملف | الأداة |
|---|---|
| `index.html` | **مركز التشخيص** (البوابة اللي بتربط الكل) |
| `founder-dependency.html` | ١ — شركتك معتمدة عليك قد إيه؟ |
| `drift.html` | ٢ — شركتك بتنحرف ناحية إيه؟ |
| `alignment.html` | ٣ — اتفاق فريق القيادة |
| `scale.html` | ٤ — جاهز تفتح فرع تاني؟ |
| `culture.html` | ٥ — ثقافة شركتك الحقيقية |
| `marketing.html` | ٦ — نظام التسويق بكام في المية؟ |
| `visionary.html` | ٧ — صاحب رؤية ولا قائد منفّذ؟ |
| `emc-capture.js` | طبقة الالتقاط (لا تحذفها) |
| `firestore-rules.txt` | قواعد الأمان (خطوة واحدة مهمة) |

## خطوة إجبارية قبل ما تبعت أي لينك (دقيقتين)
Firebase Console → مشروع **emc-crm** → Firestore → Rules → الصق محتوى `firestore-rules.txt` → **Publish**.
ده بيضيف كولكشن `emc_leads` بصلاحية **إضافة فقط** — الأدوات تكتب فيه، ومحدش يقدر يقرا بياناتك من المتصفح.

## النشر — اختار طريق واحد

**أ) على الريبو (الأنضف — بيورث نظام الـ CRM):**
حط الفولدر ده كـ `emc/lp/tools/` في الريبو واعمل push. اللينكات:
`<الدومين>/emc/lp/tools/` (المركز) و `/founder-dependency` … إلخ.

**ب) Netlify Drop (الأسرع دلوقتي — لينك في ثانيتين):**
افتح `netlify.com/drop` واسحب فولدر `tools` كله. هيديك لينك فورًا، والالتقاط في emc-crm بيشتغل زي ما هو (الملفات مكتفية بذاتها).

## اللينك اللي بتوزّعه في الميت-أب
وزّع **لينك المركز بس** (`…/tools/` أو `…/index.html`). هو اللي بياخد الاسم والرقم مرة واحدة ويفتح الأدوات السبعة. اعمله QR code وحطه على الشاشة/الاستاند.

## بيوصل فين
- بوابة المركز → `emc_leads` (source: `hub_gate`) — دي الـ lead المهمة.
- خلوص أي أداة → `emc_leads` (source: `tool_complete`) — بيقول أي أداة عملها ودرجته.
لاحقًا: دمج `emc_leads` في `emc_contacts` + الداشبورد. مش مطلوب دلوقتي.
