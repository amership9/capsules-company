# Reignite — منحني الاحتراق

أداة تشخيص جماعيّة بترفع واقع الشركة على «منحني الاحتراق»: خط النجاح الظاهر + خط الحيوية
الداخلية، والاحتراق هو الفجوة بينهم. التشخيص مرآة لا حُكم — مبني على «منظور الفؤاد».

---

## بنية الملفات

```
reignite/
├── index.html              صفحة البداية (اسم وهمي + كود الدفعة + الفئة A/B/C)
├── assessment.html         صفحة الأسئلة الـ36
├── results.html            نتيجة المستجيب الفرديّة (قراءته لحالة الشركة)
├── admin.html              لوحة الأدمن + المرآة الجماعية
├── firestore.rules         قواعد الأمان (لازم تتنشر — مهم جداً)
├── css/
│   └── styles.css          نظام التصميم
└── js/
    ├── questions.js        بنك الأسئلة (Q0 + 36 سؤال × 5 محاور)
    ├── scoring.js          المحرّك التحليلي + التجميع
    ├── readings.js         قراءات الأنواع الثلاثة بنسخ الشدة
    ├── curve.js            راسم المنحني (SVG)
    ├── firebase-config.js  تهيئة Firebase + COLLECTION + كود الأدمن
    ├── assessment.js       تدفّق الأسئلة + الحفظ
    ├── results.js          عرض النتيجة الفرديّة
    └── admin.js            لوحة التحليل + المرآة الجماعية
```

التدفّق: `index → assessment → results`، والأدمن على `admin.html`.

---

## ⚠️ خطوة إجباريّة قبل التشغيل — قواعد Firestore

الكود بيكتب في كولكشن `reignite_responses`. قواعدك الحاليّة بتسمح فقط لكولكشنات `emc_*`،
يعني **كل عمليّات الحفظ هتتمنع** لحد ما تضيف القاعدة الجديدة.

انسخ محتوى `firestore.rules` كامل في Firebase Console →
Firestore Database → Rules → Publish. القاعدة المضافة:

```
match /reignite_responses/{doc} { allow read, write: if true; }
```

(مفتوحة في مرحلة الاختبار زي باقي كولكشنات EMC. في الملف نسخة مؤمّنة مقترحة بعد تفعيل Auth.)

3. لو Pages مفعّلة، الرابط هيكون:
   `https://amership9.github.io/capsules-company/reignite/`
4. انشر `firestore.rules` (الخطوة فوق).

## كود الأدمن

موجود في `js/firebase-config.js` → `ADMIN_PASSCODE` (الافتراضي `reignite-2025`). غيّره من هناك.
التحقّق حاليّاً client-side (LocalAuth) مطابق لنهج EMC؛ مش حماية حقيقيّة — للتأمين الكامل
فعّل Firebase Auth واستبدل قاعدة Firestore بالنسخة المؤمّنة.

## كيف يشتغل

- المستجيب بيختار فئته (قيادة A / وسطى B / قاعدة C) وكود الدفعة، بيجاوب 36 سؤال،
  بتتحفظ إجابته + نتيجته المحسوبة في `reignite_responses`، وبيشوف قراءته الفرديّة.
- الأدمن بيدخل بالكود، بيحمّل دفعة بالكود بتاعها، فبيشوف: النوع الغالب، المنحني ونقطة
  «إنت هنا»، الفجوة الإدراكيّة بين القيادة والفريق (العمى)، المستويات، الفلاتر، صوت
  الشركة (مجهّل)، وتفصيل كل سؤال — وزرّ «المرآة الجماعيّة» لشاشة العرض في اللقاء.

كل التحليل مجهّل: نسب وفئات لا أسماء.
